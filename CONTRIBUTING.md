# Contributing

Thank you for considering a contribution to `rencodeplus`.

This repository exists because Xpra's own `rencodeplus` implementation is
GPLv3, while this crate is a clean-room GPL-2.0-only implementation. To
protect that provenance, contributions must follow the rules below.

## Clean-Room Rule

Do not copy, translate, adapt, or consult Xpra's GPLv3 `rencodeplus`
implementation when preparing a contribution.

Do not submit:

- code copied from Xpra or any other incompatible implementation;
- translated code from another language;
- pseudocode derived from an incompatible implementation;
- comments or tests that reveal implementation structure from incompatible
  source;
- patches generated by asking a tool to port or rewrite incompatible source.

Contributions should be based on:

- `SPECIFICATION.md`;
- public behavior observed through black-box testing;
- independently written tests and fixes;
- ordinary Rust design and documentation work.

## License

All contributions are accepted under `GPL-2.0-only`, matching the repository
license.

By submitting a contribution, you certify that you have the right to license
it under `GPL-2.0-only` and that it complies with the clean-room rule above.

## Development

Before submitting a change, run:

```console
cargo fmt
cargo test
```

For behavior changes, include tests that describe the externally observable
input and output. Keep implementation-specific assumptions out of the public
specification unless the behavior is part of the wire-format contract.
